# Brew & Bean — сайт кофейни с ИИ-бариста

## О проекте

**Brew & Bean** — веб-сайт кофейни с интерактивным меню и встроенным ИИ-бариста. Проект предназначен для демонстрации современного сайта кофейни, который позволяет пользователям изучать ассортимент напитков и десертов, а также получать персональные рекомендации с учётом вкусовых предпочтений.

Главная особенность проекта — локальный ИИ-бариста, который помогает пользователю выбрать подходящий напиток, рассказывает о составе и вкусовых характеристиках товаров.

## Основные возможности

### Сайт кофейни
- Современный минималистичный интерфейс.
- Главная страница с информацией о кофейне.
- Каталог напитков и десертов.
- Разделение меню по категориям.
- Карточки товаров с изображениями, описаниями, составом и ценами.
- Адаптация интерфейса под разные размеры экранов.

### ИИ-бариста
- Общение с пользователем на русском языке.
- Ответы на вопросы о кофе, чае, напитках и десертах.
- Рекомендации товаров из существующего меню.
- Учет вкусовых предпочтений пользователя.
- Подбор напитков с учетом таких характеристик, как крепость, сладость и наличие молока.
- Отображение рекомендованных товаров в виде карточек непосредственно в чате.
- Сохранение истории переписки и имени пользователя.

### Персонализация
Пользователь может указать своё имя и выбрать вкусовые предпочтения. Эти данные используются для персонализации взаимодействия с ИИ-бариста.

## Используемые технологии

| Технология | Назначение |
|---|---|
| HTML5 | Структура веб-страниц |
| CSS3 | Оформление и анимации интерфейса |
| JavaScript | Логика и интерактивность сайта |
| Vite | Локальный сервер разработки и сборка проекта |
| Wllama | Запуск языковой модели в браузере |
| WebAssembly | Выполнение модели в браузере |
| GGUF | Формат файла языковой модели |
| LocalStorage | Локальное сохранение пользовательских данных |

### Используемая языковая модель

В проекте используется **Qwen2.5-1.5B-Instruct-Q4_K_M** — компактная языковая модель в формате GGUF с квантованием.

Модель запускается локально в браузере с использованием Wllama и WebAssembly. Для генерации ответов не требуется отдельный сервер с языковой моделью.

### Назначение основных файлов

- **index.html** — основной HTML-документ проекта.
- **style.css** — стили, оформление элементов и анимации интерфейса.
- **app.js** — управление интерфейсом, обработка действий пользователя и взаимодействие с чатом.
- **chatbot.js** — логика ИИ-бариста, формирование запросов к модели и подбор рекомендаций.
- **model.js** — загрузка языковой модели и генерация ответов с помощью Wllama.
- **menu.js** — каталог напитков и десертов, содержащий названия, цены, описания, состав и изображения товаров.
- **Qwen2.5-1.5B-Instruct-Q4_K_M.gguf** — файл языковой модели.

## Установка и запуск

Для работы с проектом необходимы:
- Node.js;
- npm;
- Visual Studio Code или другая среда разработки.

### 1. Клонирование или загрузка проекта

Скачайте проект и откройте его папку в Visual Studio Code.

### 2. Установка зависимостей

Откройте терминал в папке проекта и выполните команду:

```bash
npm install
```

### 3. Запуск проекта

Выполните команду:

```bash
npm run dev
```

После запуска Vite выведет локальный адрес сайта, обычно:

```text
http://localhost:5173/
```

Откройте этот адрес в браузере.

## Особенности работы ИИ-бариста

ИИ-бариста использует информацию из каталога проекта для формирования ответов и рекомендаций.

При выборе вкусовых предпочтений система учитывает их при подборе товаров. Например, если пользователь выбирает предпочтение «Без молока», молочные напитки исключаются из подходящих рекомендаций.

История общения и пользовательские настройки сохраняются локально в браузере с использованием LocalStorage.

## Ограничения проекта

- ИИ-бариста консультирует по ассортименту, но не оформляет заказы и не принимает оплату.
- Ответы модели могут содержать неточности, поэтому информация о товарах должна сверяться с каталогом.
- Для работы локальной языковой модели требуется загрузка файла модели.
- Производительность генерации зависит от характеристик устройства и браузера.
- Пользовательские данные хранятся локально в браузере и не синхронизируются между устройствами.

## Назначение проекта

Проект Brew & Bean демонстрирует возможности интеграции локальной языковой модели в веб-приложение. Он объединяет стандартный сайт кофейни с интеллектуальным помощником, который делает взаимодействие с меню более удобным и персонализированным.
